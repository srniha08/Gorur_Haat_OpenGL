# Gorur Haat OpenGL Project

## Overview
A computer graphics simulation of a traditional Bangladeshi cattle market (Gorur Haat) developed using OpenGL and C++.

## Features
- 2D cattle market environment
- Animated cows
- Day/Night mode
- Keyboard controls
- Lighting effects

## Technologies Used
- C++
- OpenGL
- GLUT/FreeGLUT

## Installation
1. Clone the repository
2. Open in CodeBlocks/Visual Studio
3. Link OpenGL libraries
4. Build and Run
