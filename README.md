# Gorur_Haat_OpenGL
🐂 Gorur Haat – Interactive OpenGL Cattle Market Simulation
Overview

Gorur Haat is a 2D animated cattle market simulation developed using C++, OpenGL, GLUT, and GLU. The project recreates a traditional cattle market scene featuring animated bulls, traders, environmental effects, and interactive controls.

The simulation demonstrates fundamental concepts of Computer Graphics, including geometric modeling, transformations, animation, event handling, and real-time rendering.

Features
🐄 Animated Cattle
Multiple bulls with different colors and sizes
Realistic body structure using OpenGL primitives
Tail movement and head animation
Rope connections between cattle and owners
👨‍🌾 Cattle Traders
Multiple animated characters
Traditional clothing representation
Dynamic arm and leg movements
Character interactions with cattle
🌤️ Dynamic Environment
Moving clouds
Flying birds
Animated airplane
Trees, rocks, grass, and haystacks

Road and fencing system
🌙 Day/Night Cycle
Toggle between day and night modes

Enhanced nighttime atmosphere
🌧️ Rain Simulation
Animated raindrops
Splash particle effects

🥣 Jhalmuri Stall

🖱️ Interactive Controls
